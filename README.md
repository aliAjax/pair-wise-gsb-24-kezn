# 续编发掘簿 · 探方地层与出土物台账

田野临时表回去补录的续编工具：探方、地层、遗迹单位、坐标、出土物集中录入，自动核重号与标高衔接，待归出土物归层后才计入统计，数据可导出、可重开续整。

## 技术栈

React + Vite + TypeScript + CSS；纯函数领域核心（`src/domain.ts`），Node 内置测试运行器。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5110
npm test           # 领域规则测试（19 项）
npm run typecheck  # 应用与测试类型检查
npm run build      # 类型检查 + 生产构建
```

## 功能

### 录入
- **地层**：探方号、地层序号（由浅入深从 1 起）、顶板/底板标高、土质土色备注；支持改、删。
- **遗迹单位**：单位号（H12、F2…）、类型、坐标，可挂到某地层，层位未判明可暂不挂。
- **出土物**：探方、坐标、件数（正整数）、类别/描述；可直接归层并关联遗迹，也可先进**待归区**。

### 规则（录入即拦截 + 全簿核查双保险）
- 同一探方内地层序号**不许重号**；层位必须从 1 连续，缺号按「探方 + 缺失层序」报出。
- 底板必须低于顶板，否则判**层序倒挂**。
- 上下相邻地层标高必须接上（容差 5mm）：下层顶高于上层底报**重叠**、低于上层底报**断档**，信息含具体探方与相邻两层的标高、差值。
- 同探方遗迹单位号不许重复；同一坐标（忽略空白、大小写）不许登记两个遗迹单位。
- 遗迹/出土物只能挂到已存在的地层；挂遗迹时层位须与遗迹所在层一致。
- 删除地层：其上有遗迹则拒绝；已归层出土物自动**退回待归区**，不丢数据。

### 待归区与统计
- 未判明层位的出土物进入待归区，**不计入**任何统计；在待归区选地层（可选遗迹）点「归入」后才计入，可随时「退回待归」。

### 异常核查
- 按探方过滤；分「错误 / 提示」两级，每条点名探方、层序、类型与具体数值说明。

### 台账与续整
- **导出台账 CSV**：探方汇总、地层（含层厚、本层件数）、遗迹、出土物（待归/已统计）、异常清单；带 BOM，Excel 直接打开。
- **下载/恢复备份 JSON**：换机或归档后可恢复继续整理。
- 所有改动**自动保存到浏览器本地**（localStorage），关闭重开接着整理；「载入演示数据」内置断档、重叠、缺号、重复坐标、待归等典型样例。
