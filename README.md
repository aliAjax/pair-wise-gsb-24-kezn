# hxwl-10 考古探方记录 · 续编发掘簿

田野临时记录的续编工具：探方地层、遗迹单位、出土物坐标一回驻地即可补录，
换页不丢、重开续整，自动核查层序与标高衔接。

## 技术栈

React + Vite + TypeScript + CSS，数据存浏览器 localStorage，无需后端。

## 本地运行

```bash
npm install
npm run dev      # 开发端口 5110
npm test         # 领域规则测试（Vitest）
npm run build    # 类型检查 + 生产构建
```

## 功能

### 地层
- 录入探方、地层序号、顶/底标高、土色土质备注
- **同一探方内地层序号不许重号**，重号录入即拒
- 底标高 ≥ 顶标高判为**层序倒挂**，录入即拒
- 录新层时自动建议接续序号与顶标高（上层底标高 = 新层顶标高）

### 遗迹单位
- 登记编号（H12、M3、F2…）、类型、坐标、所属地层
- 层位未定的遗迹先放“待归层”，随时在名录中改层

### 出土物与待归区
- 未关联已归层遗迹、也未直接归层的出土物先进**待归区**，不计入分层统计
- 在待归区选遗迹+地层一键归入；只关联已归层遗迹的出土物自动随遗迹入层
- 遗迹改层，跟随它的出土物一起换层；显式归层的不受影响
- 已归层记录可改层或退回待归区

### 异常核查（按探方）
- 序号断档：指出探方与缺失的层号
- 标高断档（上下层接不上、中间缺土）：给出差值米数
- 标高重叠（下层顶高于上层底，疑似倒挂）：给出重叠米数
- 同坐标多个遗迹/出土物的重复坐标提醒
- 遗迹、出土物指向不存在地层的悬空引用
- 5mm 以内视为正常测量误差

### 台账与存档
- 导出 CSV：地层台账、遗迹台账、出土物台账（仅已归层 / 含待归）、
  按探方逐层的分层汇总表（带 BOM，Excel 直接打开）
- 录入自动保存到本机（防抖 + 关闭页面前兜底），重开页面接着整理
- 完整 JSON 存档可导出备份、换机导入；另可清空本机数据

## 代码结构

- `src/types.ts` — 领域模型
- `src/domain.ts` — 纯领域逻辑：录入校验、层位归属、异常核查、统计、CSV、存档
- `src/domain.test.ts` — 领域规则测试
- `src/useLedger.ts` — React 状态钩子与自动保存
- `src/ui/` — 各标签页界面
